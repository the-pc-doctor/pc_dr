# Skills

One directory per repeatable procedure. Create a skill only for something you
have actually repeated; a skill written before the second occurrence is a guess.

- `work-lifecycle/` — the mandatory five-stage procedure for any work that
  changes system state. Implements `doctrine/operations/work-tracking-lifecycle.md`
  and `doctrine/knowledge/documentation-placement.md`.

Service-specific maintenance skills are still to come.
