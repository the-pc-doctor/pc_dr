# Skills

One directory per repeatable procedure. Create a skill only for something you
have actually repeated; a skill written before the second occurrence is a guess.

- `work-lifecycle/` — the mandatory five stages for any work that changes system
  state. Implements the work-tracking and documentation-placement doctrine.
- `incident-triage/` — localize a vague failure report to a tier before touching
  anything. Most wasted incident time is spent fixing a healthy component.
- `service-health-pass/` — the scheduled sweep. Findings only; silence when
  there is nothing to report.
